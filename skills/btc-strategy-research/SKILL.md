# BTC 優質自動交易策略研究

研究與策略生成由執行本 Skill 的 Codex 完成。不得呼叫 MiniMax 或把閱讀、翻譯、規格提取與策略生成外包給其他模型 API。Python 只處理取得資料、確定性計算、驗證、紀錄及通知。

開始時讀取 [研究與整合設定](references/workflow.md)。需要連線、提交或移交時讀取 [Zeabur 操作與移交手冊](references/ZEABUR操作與移交手冊.md)，詳細規劃見 [計畫書](references/計畫書.md)。所有引用皆在匯出包內；另一台電腦須配置自己的 SSH 金鑰及排程。

## 每輪研究

讀取本地 research-codex/state.json 與最近研究紀錄，選擇尚未重複研究的可驗證假設。直接閱讀完整來源、官方程式或論文，保留網址、取得時間、commit 或內容指紋。不要把搜尋摘要當成完整規則。

由 Codex 將來源轉成進場、出場、方向、持倉限制、週期、參數、倉位與成交時點的明確規格。來源只做多不能加入做空；週期未指定須標為未知。缺失只能拒絕或明確建立研究變體。

先忠實重現，再獨立建立有理由的優化變體。變體記錄母策略與修改理由。每輪最多完成一個候選及兩個受控變體；沒有可信來源就保存零候選結果，不能為達配額捏造策略。

生成程式前核對現有引擎的策略介面與規格驗證器，不假設任何函式簽名。檢查來源一致性、未來資訊、重繪、多週期對齊與下一根可成交時點。用小型行情例子核對具體交易行為。

將來源證據、中文規格、生成程式、審查結果和修改理由保存到本地 research-codex/runs/<UTC時間>/。固定來源與規格可重現；每次嘗試都保存，不刪失敗案例。

## 回測與結果

生成與翻譯後的候選通過來源及技術審查，必須立即用 scripts/zeabur_bridge.py submit --dry-run 驗證，再以 submit 正式放入 Zeabur OpenClaw 待回測目錄。依手冊配置本機連線設定，不只是保存本地檔案。接收端自動生成同名 py/JSON、登記資料庫、保存中文翻譯並開放回測領取。使用現有鎖、資料快照與提交 ID 防止重複。不得呼叫舊 lab_runtime.py hunt，該入口會使用 MiniMax。

維持 BTC 累積淨報酬政策：驗證與測試各 ≥50%，各 ≥30 交易、PF ≥1.1、Sharpe ≥0.5、最大浮動回撤 ≤15%；三個測試子段至少兩段正收益；1.5 倍成本後正收益。另報 USD 表現。已查看的測試資料不宣稱為新獨立留出資料。

週期與參數挑選只用訓練及驗證資料；保存所有試驗數量。原始重現與週期／參數變體分開。歷史合格不代表可投入實盤。

## 整合失敗與通知

遠端連線不可用時仍完成可獨立完成的來源研究與本地候選；標記未提交、未回測，保留待處理狀態，不編造結果。初次執行核實連線與提交入口，完成後才停用舊 OpenClaw 搜尋排程，保留回測排程。不得存明文 SSH 密碼於 Skill 或產出。

使用者已授權每輪搜尋結果送至既有 Strategy Hunt Webhook，回測結果送至既有回測 Webhook。僅從私密設定讀取密鑰；沒有可用私密設定則記錄通知未送達並提出所缺整合資訊，不猜密鑰。回報以 HTTP 回應驗證，避免同輪重複傳送。

更新 research-codex/state.json，記錄來源指紋、研究家族、候選狀態、遠端提交與通知事件。排程不重疊；沒有可處理變化時避免在 Codex 對話重複狀態訊息，Discord 仍依已授權規則每輪回報。
