# OpenClaw 策略搜尋與回測升級

已在 Zeabur 的 OpenClaw 部署 `research-v6`。這次重點是提高策略來源、規則重現及樣本外驗證的可信度，而不是把歷史最大報酬率調高。

## 策略搜尋

- 搜尋優先考慮目前 OHLCV 資料可支援的趨勢、突破、動量、均值回歸與成交量方法；提高 Donchian、MACD、ADX、Bollinger、RSI 等可重現家族的抽樣權重，保留探索。
- 每輪三個相關查詢，最多 24 個搜尋結果、3 次來源模型分析、2 個新候選。搜尋摘要只用來排序，不能替代原始規則。
- GitHub 使用公開 Git 讀取 commit、檔案目錄及選定策略全文，不 checkout／執行來源程式，也不依賴匿名 REST API 額度。依搜尋家族排序檔案，不再把含有 `backtest` 的檔案誤當測試排除。
- 文章需有實際進出場內容。過長、讀取失敗、資料不符或規則不完整時拒絕，取消「403 後用摘要自行編策略」。
- 模型須指出原文行號；引擎自行保存逐字證據，避免模型拼接／改寫引文造成誤判。保存來源、模型輸出、commit、規則規格、程式 hash 及拒絕原因。
- 保留來源的週期、進出場、參數及穿越／持續條件。支援明確固定百分比停損停利、明確 ATR 週期與平滑方式、訊號及時間出場。複雜追蹤停損、限價管理等尚需專用實作，不擅自替換。
- 用開發期資料做確定性、截短前綴及未來資料擾動檢查。合法的過去 `shift(1)` 不會再被一律當作洩漏。
- 原始來源及實際交易訊號去重；失敗來源冷卻。舊版只因「曾見過 URL」拒絕的來源可以用新版完整規則重新審查，舊策略保留。
- 搜尋家族回饋採 **2024 驗證期**表現，避免利用保留測試期來調整搜尋權重。生成檔案數不再當成功數。
- 檔案／資料庫提交分階段，未完成提交不進回測；下輪自動恢復中斷的提交。API／資料庫故障保留重試，不冒充來源不合格。

## 回測

- 收盤後產生決策，下一根開盤執行；移除雙重位移與擅自加入的訊號邊緣過濾。
- 使用策略原本的週期及出場，不再做 28 組週期／ATR 配對後挑最大報酬。
- 檢查進場當根停損、跳空停損及期末未平倉。無法辨識單根 K 線內先後時，採停損優先，逐根計入浮動權益與回撤。
- 修正為 Binance COIN-M **BTCUSD_PERP 幣本位反向合約**損益公式；按 USD 100 面值取整合約量。`return_pct` 是 BTC 報酬，另報包含 BTC 抵押品市值變化的美元資產報酬，兩者不能直接混用。
- 計入雙邊費用、滑價、價差及資金費率。資金費率時間戳的毫秒偏移會對齊 K 線，不再因非完全相等而遺漏。
- 預設單次部位為權益的 30%；每邊費率 0.1%，進場滑價 0.04%、出場滑價 0.06%、整趟價差 0.02%。這些是固定研究假設，可透過既有執行環境變數調整，沒有依候選的測試結果找最佳費率。
- 2024 年以前作開發、2024 年作驗證、2025 年起作保留測試。測試另分三段，並以 1.5 倍費用／滑價／價差做壓力測試。
- 研究合格需驗證與測試都正報酬、各至少 30 筆交易、PF ≥ 1.10、日報酬 Sharpe ≥ 0.5、BTC 權益最大回撤 ≤ 15%；三段測試至少兩段正報酬，成本壓力仍正報酬。
- 逐筆交易與權益曲線保存在 JSON，資料 hash、規則與成本假設可追查。寫入失敗可重試，不在資料庫結果保存前推進檔案處理。

## 判讀限制

本次手動搜尋試跑尚未產生可提交的新候選或研究合格策略。實際拒絕原因包括缺少完整規則、不符原始週期、資料／市場不相容，以及向前掃描未來資料；來源與模型記錄已保存。原有定時搜尋已恢復，沒有把測試用策略或不完整來源當作正式獲利成果。

完成程式驗證不等於已找到獲利策略。研究合格也須人工核對規則及模擬交易。K 線無法完整還原盤中先後、委託簿或真實成交；資金費率以 K 線開盤價近似標記價格。持續篩選許多候選仍有多重比較風險，不能把一次合格或歷史高報酬當作未來獲利保證。

支援原始週期為 5m、15m、30m、1h、4h；日線、12h、外部資料、複雜部位管理等來源會明確拒絕，不能偷偷換週期來提高通過率。
